# SIMULATED TRAINING EXAMPLE: no internet access

Ticket: SIM-001. Fictional scenario; no commands in this report were actually run.
Impact: one training device cannot use a lab application.
Priority: Medium, because one device is blocked and no broad outage is indicated.

Simulated observations: adapter reports disconnected; Ethernet cable is loose;
no useful upstream connectivity test is possible with the physical link absent.
Simulated investigation: ask about scope and onset, inspect Settings and the lab
cable, then compare application behavior after an approved physical correction.
Hypothesis: disconnected cable prevents the interface reaching the lab network.
Simulated resolution: reconnect the cable with consent, observe the expected
address configuration and verify the original lab application works.
Final status: Resolved, pending simulated user confirmation before closure.
Escalation decision: not required in this fictional outcome; recurring link loss
or several affected devices would go to network/hardware support.
Learning: validate the physical layer before changing DNS or renewing leases.
